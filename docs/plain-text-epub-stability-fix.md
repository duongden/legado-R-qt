# 普通正文 EPUB 稳定性修复记录

本轮执行 [稳定性审查计划](plain-text-epub-stability-plan.md)，修正段评关闭后正文重入失败，以及含图章节切换时的叠影和过期画面复用。代码修复、交叉审查、签名构建和实际 APK 核验均已完成，候选版本为 `3.26.09090521-stability / 29815041`。下载与远端文件校验结果见 [候选交付记录](../output/text-reader-stability-delivery.md)。

Android 设备验收尚未完成。当前没有已连接的 Android 设备；两版官方模拟器均在启动 Android 前异常退出。下述浏览器和 JVM 结果不能证明 Android 上的两个故障已完全消失。环境证据见 [Android 环境记录](../output/text-reader-stability-android-environment.md)。

## 已实现的修复

| 链路 | 改动及作用 |
| --- | --- |
| 段评 WebView 回池 | 移除池获取、回收中的进程级计时器操作，使用实例 `onResume/onPause`。一个弹窗的异步 `about:blank` 回收不再暂停独立正文 WebView。 |
| 弹窗销毁、重建和迟到请求 | 每次创建 Fragment 视图重新获取 WebView；关闭或销毁时先取消本次租用与页面任务，再回池。异步加载、配置及 JS 结果检查页面代次，取消不会被转换成错误 HTML。 |
| 含图章节的 live 预览 | 保存目标的原始显示状态；显示透明目标时隐藏源 WebView 的像素，但保留其手势接收。已露出的目标晋升为当前章时保持正常 alpha；成功、取消和回滚均恢复最终角色对应的状态。 |
| 图片晚到、同尺寸像素变化 | 每个 WebView 文档维护独立视觉版本。变化立即作废截图；动画或交接期间保留待同步状态，结束后读取最新页码、页数与字符锚点，再处理排队翻页。 |
| 截图与预取 | 截图键增加视觉版本；独立渲染器采集前后重新核对同一文档状态。含动态源图的虚拟目标帧不直接晋升为当前页缓存，避免用不同 WebView 的局部版本证明画面一致。 |
| 同步唤醒与重试 | 补齐长按选择解锁、取消交接等收尾唤醒。旧场景重试有上限；最后一次查询期间到达的新场景信号会获得新一轮重试，不会被旧轮次的上限吞掉。 |
| EPUB 兼容性 | 普通正文要求目标页具备可见内容。原 EPUB 保留作者空白页、待加载图片页的逻辑导航，同时检查布局是否稳定、目标页与版本是否匹配；截图继续检查实际内容。 |

`sourceChapterUrl` 区分生成的普通正文和原 EPUB；没有按是否包含图片或是否启用出版者样式来推断类型。原始图片 `click` 的处理路径保留，Direct 正文继续跳过段落规则和 `pclick`。本轮没有重新设计目录、进度或独立排版配置。

## 稳定性与效率

下载中的图片不等同于待重排，正文可以先显示。图片、字体或布局变化按帧合并；浏览器中同批 80 次 DOM 属性更新只发送一次 pending 和一次 settled 通知。同步采用有界重试，并由新状态、操作或恢复事件重新唤醒，不进行永久逐帧轮询。

截图过期时保留有效正文并重新采集。以上是实现策略与局部行为验证；尚无本轮 Android 的首屏耗时、切章 p50/p95、内存或帧率对比，不能宣称设备性能已改善。

## 安装后的最小复测

在普通正文选择 EPUB 渲染，并记录手机系统、System WebView 版本、书籍章节和翻页模式。同进程复测期间保持应用运行，不以杀进程重启代替退出正文后重入。

1. 通过原始图片点击打开段评，关闭段评，退出到书架后立即重入同一本书；再打开另一本文字书和含图书。分别覆盖段评已加载、仍在加载时关闭的情况。
2. 在含图章节末页拖动到下一章后取消，检查当前页是否恢复清晰；再次完成切章，检查目标章首页和下一页，再反向跨章返回。
3. 在图片尚未加载完时重复上述跨章操作，待图片到达后检查画面、页码和阅读位置；覆盖透明 PNG 或 SVG、当前使用的翻页模式以及无动画对照。
4. 连续重复段评退出重入和正反切章，并覆盖切到后台再恢复。检查空白、透明叠影、无法翻页、错误页码及跨书互相影响；性能数据需在同一设备和书籍条件下另行测量。

这些步骤属于待执行的设备验收，不计入上面的通过数量。源码改动清单与补丁分别保存在 [改动清单](../output/text-reader-stability-change-summary.json) 和 [源码补丁](../output/text-reader-stability-source.patch)。
