# 普通正文 EPUB 排版：原文替换净化

普通正文选择 EPUB 排版后，现在可以使用原有的替换净化开关、规则管理及长按新增规则。此前菜单把替换净化一并归入 Direct 排版的限制，正文加载路径也直接跳过了替换处理。

## 处理顺序

章节读取完成后，先识别可明确去重的首标题，再按原有规则顺序处理正文原始字符串和标题，最后解析图片标签并生成排版文档。正文规则可以匹配 `<img>`、`src`、`click` 和 `<usehtml>` 等原始标签内容。生成页面中的内部属性和 JavaScript 桥接数据不参与用户替换。

处理结果不写回原始章节缓存或书籍文件。关闭、删除或修改规则后，重新从原文生成内容；不会在上一次净化结果上继续叠加替换。目录的章节索引和 URL 不变。

正文显示与朗读使用同一个处理入口和同一份结果，标题、段落及字符偏移保持一致。结果缓存限制为最多四个条目和四百万字符左右的内容预算；同一输入的并发请求合并计算。规则变更会使旧结果失效，旧会话和已取消的加载不得提交到当前正文。

后台订阅静默更新规则后，如果当前普通正文使用的规则版本确实变化，会在主线程复核书籍和处理器身份后重新加载。无关规则刷新不触发重载；换书后迟到的刷新请求会被丢弃。退出后保留的同一本书仍可能进行一次后台预处理，供无阅读页面的朗读场景使用。

单条规则失败时保留该规则执行前的内容，并继续处理后续规则；取消信号继续向上传播。原有正则和 `@js:` 执行器的超时机制仍然保留，复杂规则的执行成本也仍由规则本身决定。

## 功能范围

| 阅读模式 | 替换开关、规则管理、长按新增 | 起效的替换列表 |
| --- | --- | --- |
| 普通正文，原生排版 | 保持支持 | 保持原有行为 |
| 普通正文，EPUB 排版 | 支持 | 暂不开放 |
| 原 EPUB，Direct 排版 | 不开放 | 不开放 |

段落规则的限制保持原样。普通正文图片和气泡的默认点击高亮设为透明，样式只作用于生成的普通正文，不覆盖原 EPUB 的作者样式或文本选区。
