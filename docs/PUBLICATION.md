# Source snapshot, attribution and build

## Distribution scope

Public source snapshot prepared on 2026-10-04 for `legado-R-qt` under GPL-3.0.

This distribution excludes all four translation data
files (Names.dat, VietPhrase.dat, ChinesePhienAmWords.txt and Rule.txt), plus the
Asuka, Doraemon and Minecraft theme artwork, embedded template JSON, associated
source folders and artwork fetching/building scripts. Original notices are kept
under `docs/removed-theme-notices`; those notices do not ship the artwork.

The remaining built-ins are Lord of Mysteries and Vertical. Lord of Mysteries
becomes the default. Removed built-in IDs are retired so an old selection resolves
to an available theme. Generic icons and other documented assets remain; this is
not an image-free repository. The retained tarot artwork has public-domain source
records and included fonts retain their OFL notices.

## Translation without bundled data

The translation implementation remains, but default dictionary data is not shipped
or automatically downloaded. Missing default data loads as empty dictionaries and
no rules. Import your own permitted TXT files through the dictionary-management
settings; each type can be imported independently. The UI shows when data has not
been imported and hides restore-default when no default for that type exists.
Attempting an unavailable restore cannot erase an imported dictionary.

Optional local data may be placed under
`app/src/main/assets/translate/vietphrase/` for a private build. That path and the
four data filenames are ignored by Git. Do not commit those files. Data-dependent
regression cases skip when their optional local data is absent; synthetic parser,
engine and import tests remain runnable.

The translation port's source provenance includes
[legado-qt](https://github.com/duongden/legado-qt/tree/47d062ca3186956c397ef2d05d6ec09c3bf8b4f9)
and the GPL-3.0
[VietPhrase rule engine](https://github.com/duongden/duongden-vietphrase-translator/tree/06d9793ac757dd74e92aa175488ea6c3b1b8be20).
The translation data is distributed separately from this source snapshot.

## Build Android

Use JDK 17, Android SDK Platform 36 and the checked-in Gradle wrapper. Configure
the SDK with `ANDROID_HOME` or an untracked local.properties file on your own
machine. No signing passwords, release keys or prebuilt APKs are committed.

```sh
./gradlew :app:testAppDebugUnitTest :app:lintAppDebug :app:assembleAppDebug
```

The release build for version 3.26.1004.1 uses:

```sh
./gradlew -PVERSION_NAME=3.26.1004.1 -PVERSION_CODE=12026 :app:assembleAppRelease
```

Without private release signing properties this produces an unsigned release
APK. Sign it locally using your own release key before installing or distributing.

The default debug signing key is generated by the Android toolchain locally.
For a signed release, provide the existing RELEASE_STORE_FILE,
RELEASE_STORE_PASSWORD, RELEASE_KEY_ALIAS and RELEASE_KEY_PASSWORD Gradle
properties privately, outside version control. Do not publish a keystore.

The default version code is derived from the Git commit count. A fresh repository
has a smaller count; when building an update, supply a version code higher than
that of the installed app, for example with `-PVERSION_CODE=YOUR_VERSION_CODE`.
Updating an installed application also requires the corresponding signing key.
The existing assemble task additionally copies its APK into the checkout's parent
directory, as defined in app/build.gradle.

## Build and embed the web UI

Use Node.js 20 or newer and pnpm 9 or newer. The lockfile records the dependency
resolution used for this snapshot (validated with pnpm 10.32.1).

```sh
cd modules/web
pnpm install --frozen-lockfile
pnpm exec vue-tsc --build --force
pnpm exec vite build
```

Copy the **contents** of modules/web/dist into app/src/main/assets/web/vue,
replacing old bundle files. The existing sync script runs only when GITHUB_ENV
is set; running the commands above locally does not automatically embed assets.
The embedded web files in this export were rebuilt from its source and scanned.
No source maps, node_modules or temporary dist files are included.

## Validation limits

TypeScript checking, Vite production build, dependency lock validation,
web UI regressions at five viewport widths, theme/storage regressions, and XML
parsing passed. Browser checks used synthetic data in a temporary profile.
A separate JVM harness also compiles the actual dictionary loader/import manager
and template store against filesystem test doubles and checks startup without data,
independent imports, rollback, unavailable restore and retired-theme selection.
A full `:app:assembleAppRelease` build, including its release lint-vital checks,
passed using JDK 17 and Android SDK 36. The resulting package is
`io.legado.app.rqt.Archive`, version 3.26.1004.1 (12026), and is not debuggable.
Its ZIP contents were checked for the excluded dictionary and theme files;
the unpacked payload was also scanned for secrets and private local paths.
No instrumentation test or physical-device verification was run for this
publication task. The private audit report records the scanner results and
exclusion manifest. Secret scanning reduces risk but does not prove that arbitrary
source or binary resources contain no sensitive data.
