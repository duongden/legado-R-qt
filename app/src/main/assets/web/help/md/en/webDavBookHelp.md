# WebDAV books

The WebDAV library lists, adds and downloads book files from your server. Configure endpoint, account, password and folder permissions first.
Downloaded TXT/EPUB files still need appropriate storage access. Add remote books to the library to read. Use the local book/cache menu for upload where available.
The remote book folder differs from app backup storage. For errors, check server access, paths, application passwords, write permission and the actual file. Do not delete server files merely to resolve a library display issue.
