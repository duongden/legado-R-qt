# Source debugging

Enter a keyword to test search; use the original prefix/address examples to test Discovery, details, contents or chapter extraction.

1. Inspect the network response before changing selectors.
2. Verify URLs, counts and extracted fields, not just a success message.
3. Test several pages/chapters, error cases and sign-in where relevant.
4. Open the book in the app after debugging to verify actual behavior.
Do not share logs containing cookies, tokens, accounts or private signed URLs.
