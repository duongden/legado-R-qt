# WebDAV backup

Configure the WebDAV endpoint, account and application password supplied by your provider. A normal web password may differ from the WebDAV password.

1. Create the folder and access credentials on your service.
2. Enter endpoint/account/password in backup/restore settings.
3. Run a manual backup and verify the server file.
4. Restore only after checking the backup and current data.
Automatic backup depends on app settings; same-day backups may be overwritten. Backup is not proof of immediate reader synchronization. LAN Web Service uses the phone database without requiring WebDAV.
