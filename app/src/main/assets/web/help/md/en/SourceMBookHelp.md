# Book source management

A book source defines search, details, contents and chapter extraction. Import from files/links, create a source or export selected sources.

- Enable sources to control search scope; enable Discovery separately when category rules exist.
- Green dot: Discovery exists and is enabled. Red dot: Discovery exists but is disabled. A key icon indicates sign-in configuration.
- Use groups, filtering, multi-select and ordering to manage sources.
- Sign in on the phone. Do not include cookies, passwords or tokens when sharing a source.
- Verify search, details, contents and a real chapter after editing rules. Validation does not replace actual reading.
- Web Discovery lists enabled text Discovery sources. Adding an existing book preserves its source and reading progress.
