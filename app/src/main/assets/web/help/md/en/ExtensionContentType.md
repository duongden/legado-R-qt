# Extensions and MIME types

MIME describes the content type of an HTTP response; the extension describes the file name. They may disagree when server headers are wrong. Inspect the response and actual content.

| Group | Example MIME |
|---|---|
| Text | `text/plain`, `text/html`, `application/json` |
| Books | `application/epub+zip` |
| Images | `image/jpeg`, `image/png`, `image/webp`, `image/svg+xml` |
| Audio | `audio/mpeg`, `audio/aac`, `audio/ogg` |
| Video | `video/mp4`, `application/vnd.apple.mpegurl` |
| Fonts | `font/ttf`, `font/otf`, `font/woff2` |
MIME codes/extensions are technical identifiers and must not be translated with the interface.
