# 鎏金花笺素材

花章使用 Abraham Jacobus Wendel 为 H. Witte《Flora》绘制的牡丹版画，图版 50（1868）。

- 来源：[Wikimedia Commons — WitteHeinrichFlora1868-050-Paeonia × suffruticosa.png](https://commons.wikimedia.org/wiki/File:WitteHeinrichFlora1868-050-Paeonia_%C3%97_suffruticosa.png)
- 状态：Public domain / PD-old-100-expired / PD-Art，来源页注明公有领域。
- 本地处理：裁切、缩小到 400 × 400 并编码为 WebP，圆形花章由模板 CSS 绘制。
- `peony-cameo.webp` 为 45,512 字节。构建时直接内嵌到模板 CSS，使用模板和导出副本都无需额外网络或素材安装。

其余角饰、藤蔓、线纹、光泽和段落装饰由本项目 SVG/CSS 绘制；没有运行时远程脚本。

编辑本目录的 `page.html`、`style.css`、`script.js` 后，运行 `python tools/reader-templates/build-gilded.py` 更新打包的 `builtin.gilded.json`。用户仍可在应用中复制并编辑完整模板。
